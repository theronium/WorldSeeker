# シナリオ・イベントエディタ

WorldSeekerのシナリオ(マップ・イベント・登場人物の画像)を、ブラウザで編集するローカルツールです。仕様は [`docs/scenario_editor.md`](../../docs/scenario_editor.md)。

## 使い方

```
node server.js            # または、このフォルダの start.bat をダブルクリック
```

ブラウザで <http://localhost:8765/> を開きます(`start.bat`は自動で開きます)。Node.js 18以上が必要で、依存パッケージはありません。`--port 9000`でポートを変えられます。

| 種別 | 場所 | 用途 |
|---|---|---|
| デフォルト | `godot/scenarios/<id>/` | リポジトリに含めて公開する。保存するとリポジトリのファイルが変わる |
| カスタム | `%APPDATA%\Godot\app_userdata\WorldSeeker\scenarios\<id>\` | 個人用。公開しない(ゲームの`user://scenarios/`と同じ場所) |

環境変数`WS_CUSTOM_ROOT`、または`--custom-root <dir>` / `--default-root <dir>`で場所を変えられます(試すときは、リポジトリのシナリオを汚さないよう、複製を指すこと)。

## 画面

- **イベント**: 一覧(フロア別・条件で発生・案内会話。検索・絞り込み)と、選んだイベントの編集画面。会話は「行」のリストで、話者・左右・セリフ・画像・進み方(次の行/指定の行/終了/選択肢)を編集する。右側に、リプレイ・検証・分岐の全体図。保存はイベント単位(Ctrl+S)。
- **登場人物・画像**: 話者名→画像の割り当て(登場人物表)。画像はライブラリ(町人・敵・探索者)か、このシナリオ固有のPNG(アップロード)から選ぶ。
- **マップ**: エリア>セクション>フロアのツリー(絞り込み・エラーの印つき)と、選んだものの編集フォーム。フロアの追加・削除・名前・ID・所属セクション・マップ上の位置、接続(双方向)、ゲート(戦闘/技能/アイテム/生まれ)、突破報酬、セクション・エリアの追加・削除・並べ替え、アイテム定義。IDを変えると参照(接続・所属・アイテム・イベント)も付け替わる。保存はマップ全体(Ctrl+S)で、保存するまで「元に戻す」で取り消せる。エリア・セクション・フロアの並びが、ゲームでの倍率・退避先・マップ画面の配置になる(詳細は[`docs/scenario_editor.md`](../../docs/scenario_editor.md)の「マップの編集」)。
- 上のバー: シナリオの切り替え・基本情報(名前・説明・暦の開始)・新規・複製(デフォルトへ複製すれば「公開する」に昇格)・削除・**zip書き出し**・**zip取り込み**・全体の検証。
- **スマホへの持ち込み**: 「zip書き出し」で、開いているシナリオを1つのzip(`worldseeker_scenario_<id>.zip`。保存済みの内容)にする → スマホの端末内へ運ぶ(USB転送・`adb push`など。ファイル選択にGoogleドライブは並ばない)→ ゲームのセーブ/ロード画面の「シナリオを取り込む」。ゲームで削除するのは「カスタムシナリオの管理」。「zip取り込み」は、書き出したzip(バックアップ・他のPCや人から受け取ったもの)をエディタへ読み込む(同じIDがあれば、上書きの確認。標準のシナリオは上書きできない)。仕様は[`docs/scenario_editor.md`](../../docs/scenario_editor.md)の「スマホへの持ち込み」。

**ゲームへの反映**: エディタで保存した内容は、ゲームの「セーブ/ロード」画面で**そのシナリオを選んで「新規プレイを開始する」**と反映されます。遊び始めたセーブスロットは、その時点の内容のまま続きます。

## テスト

```
node --test test/logic.test.js test/server.test.js test/worldlogic.test.js test/zip.test.js   # ロジック・サーバー・マップの編集ロジック・zip(41件)
node test/browser-smoke.js [スクリーンショットの保存先]  # 実際のEdge/Chromeを操作して画面を通しで確認
```

`browser-smoke.js`は、一時ディレクトリに複製したシナリオで動くので、リポジトリのシナリオには触れません(ブラウザが見つからなければ何もせず終了)。
